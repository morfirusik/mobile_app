# Shymkent Run

Готовый презентационный сайт в формате мобильного приложения. React 19, TypeScript и Vite. Русский и казахский интерфейсы, адаптация для телефона, планшета и ноутбука. Все иллюстрации встроены: внешние изображения, карты, шрифты и API не нужны.

## Запуск без установки

Откройте **`dist/Shymkent-Run.html`** в современном Chrome, Edge, Safari или Firefox. Весь сайт находится в одном файле, интернет и Node.js для показа не требуются.

Файл создаётся командой `npm run build`. Для публикации можно переименовать его в `index.html` и загрузить на статический HTTPS-хостинг. Можно также разместить всю папку `dist` без изменений. Серверная часть и API-ключи не нужны.

Данные привязаны к браузеру и адресу файла/сайта. При переходе с автономного файла на размещённый сайт история не переносится. Если браузер запрещает сохранение, приложение сообщает об этом и работает до закрытия страницы.

## Разработка

Нужен Node.js 22.12+ или 24 LTS и npm.

```bash
cd mobile_app
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. Для остановки сервера нажмите Ctrl+C.

```bash
npm run build      # TypeScript, сборка сайта и автономного HTML
npm run preview    # Проверка собранного сайта через сервер
npm test           # Тесты баллов, наград, воды и сброса
npm run test:e2e    # Пользовательские сценарии в Chromium
```

Перед браузерными тестами выполните `npm run build` и, если Chromium не установлен, `npx playwright install chromium`. В облачной среде используется `/usr/bin/chromium`; другой путь можно задать переменной `PLAYWRIGHT_CHROMIUM_PATH`.

## Возможности

- Демо-вход, редактирование ФИО, логина, возраста, роста, веса, города, телефона и категории. Пароль не нужен.
- Главная с целью недели, активностью, балансом, маршрутами и водой.
- Бег, спортивная и пешая ходьба: старт, пауза, продолжение, завершение, отмена.
- Анимация маркера на схеме. Демо-время ускорено в 15 раз. «Показать финиш маршрута» завершает дистанцию сразу.
- История и подробности тренировок, график за 7/30 дней, рекорды и приблизительная оценка калорий.
- Челленджи: вступление до тренировки, прогресс, однократное получение награды.
- Рейтинг по заработанным баллам с фильтром по категориям. Трата баллов не снижает рейтинг.
- 10 баллов за километр с округлением вниз. Купоны за баллы, проверка баланса, защита от повторного получения купона.
- Благотворительность с виртуальными баллами, прогрессом проектов и историей.
- Демо-запись на встречи сообщества и достижения за участие.
- Вода по текущей локальной дате, добавление/удаление стакана и настройка цели.
- Справочник продуктов, поиск, категории, расчёт калорий и БЖУ для порции.
- Разминка, советы по здоровью, демо-ассистент с подготовленными ответами и текущими результатами пользователя.
- Русский и казахский языки, настройки, подтверждаемый сброс демо.

## Сценарий защиты — 3–5 минут

1. Нажмите **«Войти в демо»**. Покажите главную и переключение языка.
2. **«Челленджи и рейтинг» → «Первый шаг» → «Присоединиться»**.
3. **«Маршруты» → «Парк Независимости» → «Посмотреть маршрут» → «Выбрать маршрут»**.
4. Начните демо-пробежку. Покажите движение маркера, паузу и продолжение. Нажмите **«Показать финиш маршрута»**.
5. Результат: **2,5 км, 15:00 и +25 баллов**. Перейдите к достижениям и заберите **+30 баллов** за челлендж.
6. В партнёрах выберите **magnum** и обменяйте **50 баллов** на демо-купон.
7. В **«Добрых делах»** передайте **50 баллов** проекту. Баланс станет **135**, рейтинг — **235** заработанных баллов.
8. Покажите стакан воды, расчёт порции, ответ ассистента и профиль.
9. Обновите страницу: профиль, баллы и результаты сохранятся.

Перед новым показом: **«Профиль» → «Настройки» → «Сбросить демо к началу»**. После подтверждения вернутся 180 баллов, три примера тренировок и исходный профиль.

## Границы MVP

Это демонстрационный проект. GPS и датчики телефона не используются. Маршруты — условные схемы, не для реальной навигации. Каратау обозначен как загородный маршрут. Сити-парк и Японский парк отсутствуют.

Соперники, встречи и благотворительные сборы вымышлены. Купоны не дают реальных скидок; договорённости с компаниями не заявлены. Денежных платежей, серверной регистрации, отправки личных данных, настоящего ИИ и фоновых push-уведомлений нет. Напоминание о воде доступно внутри центра уведомлений приложения.

## Структура

```text
src/
  App.tsx                 # Оболочка, вход, навигация, уведомления
  data.ts                 # Маршруты, продукты, партнёры и переводы
  store.ts                # Состояние, сохранение и правила баллов
  ui.tsx                  # Общие элементы, иллюстрации, схема
  styles.css              # Адаптивный интерфейс
  screens/
    Activity.tsx          # Главная, маршруты, тренировки, статистика
    Community.tsx         # Челленджи, рейтинг, партнёры, благотворительность
    Personal.tsx          # Здоровье, ассистент, профиль, настройки
  store.test.ts           # Тесты бизнес-логики
 tests/demo.spec.ts        # Браузерные сценарии
 scripts/export-demo.mjs   # Экспорт автономного HTML
```

Данные сохраняются в `localStorage`, ключ `shymkent-run:v1`. Чат ассистента временный, на сервер не отправляется. Иллюстрации созданы в SVG, иконки — Lucide (ISC).
